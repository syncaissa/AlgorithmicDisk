# Demo: ten files through one AlgorithmicDisk

```
python3 make_inputs.py     # builds InputFiles/ (needs PyMuPDF; downloads public-domain books and a NASA video)
python3 run_demo.py all    # write AlgorithmicDisk/ -> read OutputFiles/ from the disk alone -> REPORT.md, report.json
python3 run_demo.py read   # regenerate OutputFiles/ again from the disk folder only
```
Folders: `InputFiles/` (10 files, 1-5 MB each: 4 text, 3 PDF, 3 video), `AlgorithmicDisk/` (engines/, seeds/, manifests/,
INDEX.json — everything needed to regenerate), `OutputFiles/` (regenerated). `REPORT.md` compares them byte-for-byte.
`OutputFiles/` is regenerable and can be deleted; `InputFiles/` is rebuilt by `make_inputs.py`.

Sources: books and the Cinderella text from Project Gutenberg (public domain); the MP4 is NASA Goddard's
"2016 Mercury Transit" (public domain); the two animations are generated by `anim_generator.py` (also stored on the disk
as engine ANET-PROC-anim-v1); the PDFs are built with PyMuPDF from the Gutenberg texts.
